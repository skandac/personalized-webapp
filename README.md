# Portfolio Website

A modern, responsive, and beautiful portfolio website built with HTML, CSS, and JavaScript.

## Features

- 🎨 **Modern Design**: Clean and professional design with smooth animations
- 📱 **Responsive**: Fully responsive design that works on all devices
- ⚡ **Fast Loading**: Optimized for performance with minimal dependencies
- 🎯 **Interactive**: Smooth scrolling, hover effects, and dynamic navigation
- 📧 **Contact Form**: Functional contact form with validation
- 🌟 **Animations**: Beautiful animations and transitions throughout

## Sections

1. **Hero Section**: Eye-catching introduction with call-to-action buttons
2. **About Section**: Personal information and statistics
3. **Skills Section**: Technical skills organized by category
4. **Projects Section**: Featured projects with descriptions and links
5. **Contact Section**: Contact information and working contact form

## Customization

### 1. Personal Information
Edit the following in `index.html`:
- Replace "Your Name" with your actual name
- Update the hero subtitle and description
- Modify the about section content
- Update contact information (email, phone, location)

### 2. Skills
In the skills section, update the skill items to match your expertise:
- Modify the skill categories (Frontend, Backend, Tools)
- Add or remove skill items
- Update the icons (using Font Awesome classes)

### 3. Projects
Replace the sample projects with your actual projects:
- Update project titles and descriptions
- Add your actual project links (GitHub, live demo)
- Modify the tech stack tags
- Add or remove projects as needed

### 4. Styling
Customize the appearance in `styles.css`:
- Change the color scheme by updating CSS variables
- Modify fonts by updating the Google Fonts import
- Adjust spacing, sizes, and animations as desired

### 5. Contact Form
The contact form is currently set up for demonstration. To make it functional:
- Connect it to a form service like Formspree, Netlify Forms, or your backend
- Update the form action and method in the HTML
- Modify the JavaScript form handling in `script.js`

## Deployment

### Option 1: GitHub Pages
1. Create a new repository on GitHub
2. Upload your files to the repository
3. Go to repository settings
4. Scroll to "Pages" section
5. Select "Deploy from a branch" and choose "main"
6. Your site will be available at `https://yourusername.github.io/repository-name`

### Option 2: Netlify
1. Go to [netlify.com](https://netlify.com)
2. Drag and drop your project folder
3. Your site will be deployed instantly
4. You can customize the domain name

### Option 3: Vercel
1. Go to [vercel.com](https://vercel.com)
2. Import your project from GitHub or upload files
3. Deploy with one click
